# Musterlösung: Von Markdown zu HTML --- ## ✅ Aufgabe 1b: Was passiert im Hintergrund? Beim Exportieren einer Markdown-Datei als HTML erzeugt das Plugin automatisch eine Webseite. Es wandelt die Markdown-Syntax in standardisierte HTML-Tags um. Der HTML-Code wird dann in eine Datei geschrieben, die im Browser wie eine normale Webseite angezeigt werden kann. **Beispiel:** Markdown: ```markdown ## Überschrift Das ist ein *Text*. ``` HTML: ```html

Überschrift

Das ist ein Text.

``` --- ## 🔍 Aufgabe 2a: HTML-Tabelle untersuchen ### Tabelle in Markdown ```markdown | Tag | Fach | Zeit | |-----------|------------|-------------| | Montag | Mathe | 08:00–09:30 | | Dienstag | Info | 10:00–11:30 | ``` ### In HTML umgewandelt: ```html
Tag Fach Zeit
Montag Mathe 08:00–09:30
Dienstag Info 10:00–11:30
``` ### Bedeutungen der Tags: - ``: Start der Tabelle - ``: Kopfbereich der Tabelle - ``: Tabellenzeile („table row“) - ``: Körper der Tabelle (optional, meist automatisch ergänzt) --- ## 🤔 Aufgabe 2b: Unterschiede zwischen Markdown und HTML | Markdown | HTML | |-----------------------------------|--------------------------------------| | Einfach zu lesen und schreiben | Genauer und flexibler | | Wenige Zeichen für Formatierung | Viele verschiedene Tags notwendig | | Fokus auf Inhalt | Fokus auf Struktur und Darstellung | | Kein Styling möglich | CSS und Layout möglich | | Schnell und übersichtlich | Technisch, dafür sehr mächtig | --- ## 🎨 Aufgabe 3: HTML ### Teil 1: Spickzettel-Vergleich | Markdown | HTML | |-----------------------------------|---------------------------------------| | `## Mein Rezept` | `

WebStorm bietet folgende Hilfestellungen: - Syntax-Hervorhebung: Tags, Attribute und Inhalte werden farblich hervorgehoben. - Einrückung & Struktur: Der Code ist automatisch eingerückt und damit besser strukturiert. - Tooltips & Autovervollständigung: Beim Überfahren eines Tags mit der Maus ("Hovern") zeigt WebStorm Hinweise an, und beim Tippen werden passende HTML-Tags vorgeschlagen. - Live-Vorschau: Man kann die HTML-Datei direkt in WebStorm rendern lassen (per Plugin oder integriertem Vorschaufenster). - Fehlermeldungen: Ungültige oder vergessene Tags werden visuell markiert.
